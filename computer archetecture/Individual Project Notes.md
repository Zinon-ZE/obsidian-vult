### What are CPU cores?

CPU stands for Central Processing Unit, which is essentially the brain of your computer. Each CPU core contains its own execution units, registers, and pipeline, allowing it to execute instructions independently of the other cores.

### Single Core vs Multi Core

#### Defination
- A single-core CPU has a single execution unit and set of registers implemented on a single package.
- A Multi-core CPU is essentially multiple processors combined in the same package.  This means that there are multiple execution units and sets of registers.

## How to improve CPU effiency

To make efficient CPU is to improve the operation of the instruction pipeline. The basic approach is to do the most amount of work possible in a single clock cycle.

- This can be achieved through ***simultaneous multithreading (SMT),*** referred to as HyperThreading by Intel.

SMT allows the threads to run through the CPU
at the same time. This reduces the amount of “idle time” the CPU spends waiting for
new instructions to process.

## Good for workstation

1. SMP

- to use two or more physical CPUs, referred to as ***symmetric multiprocessing (SMP)***

An SMP-aware OS can then make efficient use of the processing resources available to run application processes on whichever CPU is “available.”

This approach is not dependent on software applications being multithreaded to deliver performance benefits.

- **Limitation**

However, a ***multi-socket*** motherboard is significantly more costly.

> [!NOTE]
> The CPUs used in each socket must be identical models and specifications and must be models that support SMP.
